# missing-data
# Сравнительный анализ методов заполнения пропусков в табличных данных

## О проекте

Данный проект посвящён всестороннему сравнению эффективности различных методов импутации (заполнения) пропущенных значений в табличных данных. Пропуски — одна из самых частых проблем при подготовке данных для машинного обучения, и их некорректная обработка может привести к искажению распределений, смещению оценок и снижению качества моделей.

**Цель исследования** — оценить, как методы заполнения влияют не только на точечную близость восстановленных значений (RMSE, MAE), но и на сохранение одномерных и многомерных распределений исходных данных, а также на итоговую производительность моделей машинного обучения (классификация и регрессия).

## Методология

### Типы пропусков
Эксперименты проводились для трёх механизмов пропусков (по классификации Рубина):
- **MCAR** (Missing Completely at Random) — пропуски случайны и не зависят от данных.
- **MAR** (Missing at Random) — вероятность пропуска зависит от наблюдаемых признаков.
- **MNAR** (Missing Not at Random) — пропуск зависит от самого пропущенного значения.

Для каждого типа рассматривались доли пропусков: **5%, 15%, 30%, 50%**.

### Рассматриваемые методы заполнения
| Категория | Методы |
|-----------|--------|
| **Простые (константные)** | Заполнение средним (Mean), медианой (Median), модой (Mode), нулём (Null) |
| **На основе близости** | KNNImputer (k ближайших соседей) |
| **Итеративные регрессионные** | MICE (Multiple Imputation by Chained Equations) |
| **Ансамблевые** | missForest (Random Forest) |

### Метрики качества заполнения (3 класса)
Для оценки того, насколько хорошо метод восстанавливает данные, использовались три группы метрик (согласно [Shadbahr et al., 2023]):

| Класс | Метрики | Что оценивают |
|-------|---------|----------------|
| **Точечные** | RMSE, MAE, R² | Близость заполненных значений к истинным (попиксельно) |
| **Одномерные распределения** | KL-дивергенция, статистика Колмогорова–Смирнова, расстояние 2-Wasserstein | Сохранение распределения каждого признака по отдельности |
| **Многомерные распределения** | Sliced Wasserstein Distance | Сохранение совместного распределения всех признаков (корреляционные структуры) |

### Два уровня турниров

#### Уровень 1: Турнир методов заполнения
Для каждого датасета, каждого типа пропусков и каждой метрики качества вычислялось, какой метод заполнения (KNN, MICE, missForest, Mean, Median, Mode, Null) показывает лучший результат. Методы ранжировались турнирным способом с учётом статистической неразличимости (разница < 1% даёт одинаковый ранг).

#### Уровень 2: Турнир метрик качества заполнения
**Цель** — выяснить, какая из трёх групп метрик (точечные, одномерные, многомерные) лучше предсказывает итоговое качество моделей ML.

**Как проводился:**
1. Для каждого метода заполнения получали вектор из k метрик (например, RMSE, KL, Sliced Wasserstein).
2. Обучали модели (LinearRegression, RandomForest, XGBoost) на заполненных данных и измеряли их качество (R² для регрессии, F1 для классификации).
3. Вычисляли **корреляцию** (KL-дивергенция и Kendall Tau) между:
   - распределением метрик качества заполнения (по разным датасетам)
   - распределением метрик качества моделей (R²/F1)
4. Метрики качества заполнения, показавшие более высокую корреляцию, получали лучший ранг в турнире.

**Результат турнира метрик** (из вашего PDF, страница 9): многомерные метрики (Sliced Wasserstein) оказались наиболее предсказательными для качества моделей, особенно для ансамблевых методов (Random Forest, XGBoost). Точечные метрики (RMSE/MAE) часто вводят в заблуждение — метод может иметь низкую RMSE, но полностью разрушить многомерную структуру.

### Оценка влияния на модели ML
Для каждого метода заполнения обучены три типа моделей:
- Линейные модели (LinearRegression / LogisticRegression)
- Случайный лес (RandomForestRegressor / RandomForestClassifier)
- Градиентный бустинг (XGBRegressor / XGBClassifier)

Качество оценивалось по **R² (для регрессии)** и **F1-мере (для классификации)**.

### Ранжирование (для обоих турниров)
Использовался подход, адаптированный из WMT22 Metrics Shared Task:
- Методы (или метрики) получают одинаковый ранг, если разница в качестве < 1%.
- Итоговый рейтинг — средневзвешенный ранг по 96 датасетам (44 регрессии, 52 классификации) с учётом весов:
  - 50% веса — тип и процент пропусков (MNAR_50 > MCAR_5)
  - 50% веса — тип задачи (регрессия сложнее классификации)
